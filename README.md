# Практика 6 курс, Синергия.  WorkNoteBook

**WorkNoteBook** — клиент-серверное мобильное приложение для ведения рабочих заметок и планирования встреч. Реализовано в рамках практического задания и демонстрирует гибридную модель хранения данных (локально + удалённо) с возможностью выбора пользователем стратегии синхронизации.

---

## Функциональные возможности

### Управление заметками
- Создание, редактирование, архивирование, мягкое удаление заметок (с возможностью восстановления с сервера).
- Заметка содержит: заголовок, содержимое, дату создания/обновления, возможность установки приоритета (`Высокий` / `Нормальный` / `Низкий`).
- Заметки могут быть как самостоятельными, так и относящимися к конкретной встрече.
- Заметки показаны пользователю в соответствии с выставленным приоритетом, отсортированные по дате / времени последнего изменения. Для удобства пользователя реализована возможность поиска по заметкам и возможность установки удобных пользователю параметров сортировки и фильтрации.

### Управление встречами
- Создание, редактирование, архивирование, мягкое удаление записей встреч (с возможностью восстановления с сервера).
- Встречи выведены пользователю в календарной разбивке, по дням, отсортированные по времени начала.
- Для удобства, у пользователя есть возможность перехода к указанной дате, и смены стандартных настроек сортировки (фильтрации) вывода.
- В рамках каждой встречи возможно ведение заметок (протоколов встречи)


### Режимы работы с данными (на выбор пользователя)

- **Локальный режим** — все операции выполняются только в локальной БД, связь с сервером отсутствует.
- **Серверный режим** — приложение работает исключительно с данными на бэкенде (локальное хранилище используется как кэш или временное хранилище).
- **Гибридный режим с синхронизацией** — изменения применяются локально и затем асинхронно синхронизируются с сервером. Конфликты разрешаются по времени последнего изменения.

Выбор режима осуществляется в настройках приложения. Для каждого типа объектов (заметки, встречи) можно индивидуально настроить стратегию хранения.

## Развёртывание и запуск локально

### Предварительные требования

- **Android Studio** (версия Hedgehog или новее)
- **Git**
- **JDK 11** или выше
- **Android SDK** (недостающие компоненты будут предложены при синхронизации)

### Инструкция
1. **Клонирование репозитория** 

   ```bash
   git clone https://github.com/Ensin1031/WorkNoteBook.git
   ```
   
2. **Открытие в Android Studio**  
    - Запустите Android Studio.  
    - Выберите **File → Open...** и укажите путь к склонированной директории WorkNoteBook (корневой каталог, содержащий settings.gradle.kts).

3. **Синхронизация Gradle**  
    - При необходимости подтвердите установку отсутствующих SDK компонентов.  
    - Дождитесь завершения синхронизации (статус BUILD SUCCESSFUL в нижней панели).

4. **Запуск серверной (бэкед) части проекта**  
    - Запустите локальный бэкед-сервер для работы с проектом, в соответствии с имеющейся в репозитории инструкцией: [OrganizationNoteBack](https://github.com/Ensin1031/OrganizationNoteBack)

5. **Запуск приложения**  
    - Подключите устройство по USB (с включённой отладкой) или создайте виртуальное устройство через Device Manager.  
    - Запустите приложение через RUN.

## Планируемые доработки              
- Реализация iOS-версии с использованием Kotlin Multiplatform Mobile.
- Поддержка файлового хранилища (экспорт/импорт заметок в виде текстовых файлов).
- Облачная синхронизация через Firebase или собственный бэкенд.
- Улучшение системы разрешения конфликтов при синхронизации.
